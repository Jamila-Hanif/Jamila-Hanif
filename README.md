## 🕋 Hujjaj Helper

**Guiding pilgrims. Empowering agents.**

Hujjaj Helper is a dual-role web application designed to make the Hajj and Umrah journey easier, safer and better connected.

### For Pilgrims

* 🗺️ Interactive Haram navigation
* 🧭 Qibla compass
* 🕌 Prayer-time information
* 💬 Group communication and location sharing
* 🎒 Pilgrimage preparation tools
* 🌐 English and Arabic support

### For Agents

* 👥 Client management
* 📋 Visa-status tracking
* 💳 Payment tracking
* 📊 Operational dashboard
* 📢 Group broadcast messaging
